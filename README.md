# MediNavi JAPAN

訪日外国人向けの、東京の医療機関案内アプリです。

公開サイト: https://medinavi-japan.vercel.app/

## ソースの場所

このリポジトリの直下がアプリ本体です。旧 `tokyo-med-guide` リポジトリに残っていた
以前の静的サイトを分離し、2026-09-08時点の最新版だけを収録しています。

公開中のVercelデプロイは、同じアプリコードと4,430件の医療機関データを使って
ビルドが完了しています。

## 起動・検証

Next.js 16.2.9 / React 19.2.4 / TypeScript / Tailwind CSS v4。
以下はNode.js 24で検証しています。

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

テストはNode.jsのTypeScript実行機能を使います。
`npm run dev` と `npm run build` の前に、圧縮済みの医療機関データを
`public/data/clinics.json` へ自動復元します。

## データと制約

- 4,430件。電話番号以外の既存データの記録上の更新日は全件2025-12-01。
- 電話番号は2026-09-08に公的資料から4,316件を補完。残る114件は名称・住所の相違や番号の欠損などで保留。
- 確認済み施設0件、座標0/0が30件、Webサイト未収録720件。電話番号の資料照合を施設への電話確認と同一には扱いません。
- 電話番号の出典・照合方法・保留理由は [docs/PHONE_DATA.md](docs/PHONE_DATA.md) を参照。
- 自費診療・保険証なしの受診可否は全件未収録。
- カード・海外保険・予約不要の値は全件false。実際の非対応を確認した記録としては扱えません。
- 情報の不足は、対応施設が存在しないことを意味しません。
- 通常診療時間から日本時間で目安を算出します。リアルタイムの受入状況ではありません。
- 祝日、時間の欠損・不正形式・曖昧な日またぎ時間帯は「要確認」です。
- 祝日カレンダーは2026–2027年の内閣府公表分に対応。対象年外は「要確認」となります。
  出典: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html

## 今回の修正

- 緊急時ガイドの固定された新宿の住所を撤去し、操作時に取得した位置を表示。
- 座標不明施設の誤った距離を非表示にし、日本語の施設名・住所で地図検索。
- 100件ずつページを切り替えて全件を閲覧可能に。
- 診療科の欠損施設を、指定した診療科の検索結果に混ぜない。
- 診療時間を日本時間で統一。時間不明を開院中と扱わず、毎分更新。
- データの読込失敗と検索0件を区別。
- 「電話・AIで確認済み」「リアルタイム」など裏付けのない説明を修正。
- 主要な追加表示を5言語に対応。HTMLの言語属性と言語選択のラベルを更新。
- /consultation に看護師相談の案内と任意のStripe Payment Link接続を追加。
- 電話番号4,316件と出典・取得日を追加。電話ボタンの番号形式を検証し、不明な施設はナビイの該当ページへ案内。

## 地図

Google Maps APIは呼び出しません。外部地図リンクと、操作時に読み込むOpenStreetMap埋め込みを使用します。
距離計算は端末内で行います。地図を開くと表示地点が地図事業者へ送られます。

## 有料相談の設定

初期状態はNurse Guide Japanの説明・料金・連絡先への案内だけです。
料金、連絡先、対応時間、キャンセル条件、必要な事業者表示を確定してから、
Stripeで対象サービスのPayment Linkを作成してください。

Vercelの環境変数 `CONSULTATION_PAYMENT_LINK` に
`https://buy.stripe.com/...` の実際のリンクを設定し、再ビルド・再デプロイします。
空欄・不正なURLでは決済ボタンを表示しません。Previewではテスト用リンクを使ってください。

人が受付・入金確認・サポート開始を行う方式です。会員コンテンツの自動解放は実装していません。
自動解放には認証、注文DB、署名検証付きWebhook、重複処理防止などが必要です。
支払い画面への遷移だけで入金済みと扱わず、Stripe管理画面で確認してください。
医療相談の詳細を決済メタデータに入れないでください。

参考: https://docs.stripe.com/payment-links/create
