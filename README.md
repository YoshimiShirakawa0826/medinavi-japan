# MediNavi JAPAN

訪日外国人向けの、日本全国47都道府県の医療機関案内アプリです。

公開サイト: https://medinavi-japan.vercel.app/

## ソースの場所

このリポジトリの直下がアプリ本体です。旧 `tokyo-med-guide` リポジトリに残っていた
以前の静的サイトを分離し、2026-09-08時点の最新版だけを収録しています。

この変更では厚生労働省の医療情報ネット（ナビイ）オープンデータを取り込み、
87,870施設を検索できます。以前の東京4,430施設の出典付き情報を保持しています。
公開サイトへの反映は、この変更のレビュー・デプロイ後です。

## 全国版（2026-10-20）

- トップ・施設一覧・症状検索に47都道府県の選択を追加。地域はURLに保存し、詳細から戻っても維持します。
- 都道府県の変更で以前の駅・現在地・距離・ページを解除。東京の駅は東京を選んだときの追加条件です。
- 出典は[医療情報ネット](https://www.iryou.teikyouseido.mhlw.go.jp/znk-web/juminkanja/S2300/initialize)と、同サービスの[厚労省オープンデータ配布ページ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/newpage_43373.html)。2026-06-01時点の病院7,715件・診療所80,155件を使用しています。
- 全国検索は読み取り専用SQLiteで絞り込み、20件ずつAPIで取得します。詳細も索引から1施設だけ取得し、全件JSONや都道府県全体を展開しません。データベースをNext.jsのファイルトレースに明示的に含めています。
- 新規施設は未確認から開始し、外国語対応は公式サイトの明記を確認できた施設に出典付きで補足しています。英語表記やサイトの翻訳機能だけで英語診療対応と判断しません。未確認の営業時間や当日の受入可否は推測しません。
- 新規施設の診療科は公開された診療科票から取得。診療科別・不定期の休診条件を施設全体の営業時間にまとめず、時間は要確認としています。
- 複数言語の画面表示は、施設がその言語で診療できることを意味しません。施設名・住所の翻訳がない場合は原文を表示します。
- Google Fontsへのビルド時通信をなくし、同じPlus Jakarta Sansをライセンス付きで同梱しています。

データの件数、制限、検証、更新方法は [全国データの記録](docs/NATIONAL_DATA.md) を参照してください。
脆弱性対応、検索の軽量化と検証結果は [検索環境とセキュリティ改善](docs/SEARCH_SECURITY_2026-10-20.md) を参照してください。
公式サイトによる言語情報と確認範囲は [言語対応の追加確認記録](docs/WEBSITE_LANGUAGE_REVIEW_2026-10-20.md) を参照してください。
全URLの取得・施設別結果一覧の作成方法は [調査処理の説明](docs/WEBSITE_LANGUAGE_AUDIT.md) に記載しています。
42,311 URLの一次処理結果を [施設別CSV（gzip）](public/reports/clinic-language-status-2026-10-20.csv.gz) と
[集計JSON](docs/clinic-language-audit-2026-10-20.json) に保存しました。取得の一巡は、全施設の診療言語確認完了とは区別しています。

## 起動・検証

Next.js 16.4.2 / React 19.2.4 / TypeScript / Tailwind CSS v4。
以下はNode.js 24で検証しています。

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

テストはNode.jsのTypeScript実行機能を使います。
`npm run dev` と `npm run build` の前に、圧縮済みの医療機関データを
`data/generated/clinics.sqlite` へ自動復元します。入力と出力のハッシュが一致する場合は再利用します。

## データと制約

- 既存の東京4,430件の記録上の更新日は2025-12-01。全国データの基準日は2026-06-01です。電話・カード・保険・予約条件の出典と確認日は別に保持し、一律に新しい日付へ書き換えません。
- 電話番号は2026-09-08に公的資料から4,316件を補完。残る114件は名称・住所の相違や番号の欠損などで保留。
- 施設への直接確認済み0件、座標0/0が30件、Webサイト未収録720件。公開資料の照合を施設への電話確認と同一には扱いません。
- 電話番号の出典・照合方法・保留理由は [docs/PHONE_DATA.md](docs/PHONE_DATA.md) を参照。
- 自費診療・保険証なしの受診条件は一部の公式サイト確認情報のみで、全施設を網羅しません。
- 2026-09-13に、前回確認した10施設以外の4,420施設を対象に医療情報ネットの詳細情報を取得。カード、日本の健康保険、診療科別の予約外診察、外国語対応の予約条件を追加しました。照合不一致・明確な回答のない項目は未確認です。
- 追加情報は `accessEvidence` が出典付きの正本です。元データに残るカード・海外保険・予約不要の `false` はプレースホルダーであり、実際の非対応を表しません。
- 日本の健康保険と海外旅行保険を区別。旅行保険への対応記載だけでは直接請求・キャッシュレス対応と扱いません。
- 件数・出典・保留理由・再更新手順は [2026-09-13の調査記録](docs/ACCESS_REVIEW_2026-09-13.md) と [取得マニフェスト](data/nabii-access-manifest.json) を参照。
- 情報の不足は、対応施設が存在しないことを意味しません。
- 通常診療時間から日本時間で目安を算出します。リアルタイムの受入状況ではありません。
- 祝日、時間の欠損・不正形式・曖昧な日またぎ時間帯は「要確認」です。
- 祝日カレンダーは2026–2027年の内閣府公表分に対応。対象年外は「要確認」となります。
  出典: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html

## 今回の修正

- 緊急時ガイドの固定された新宿の住所を撤去し、操作時に取得した位置を表示。
- 座標不明施設の誤った距離を非表示にし、日本語の施設名・住所で地図検索。
- 20件ずつページを切り替えて全件を閲覧可能に。
- 診療科の欠損施設を、指定した診療科の検索結果に混ぜない。
- 診療時間を日本時間で統一。時間不明を開院中と扱わず、毎分更新。
- データの読込失敗と検索0件を区別。
- 「電話・AIで確認済み」「リアルタイム」など裏付けのない説明を修正。
- 主要な追加表示を5言語に対応。HTMLの言語属性と言語選択のラベルを更新。
- /consultation に相談窓口を追加（2026-10-05に決済を撤去し、オンライン診療サポートへ変更）。
- 電話番号4,316件と出典・取得日を追加。電話ボタンの番号形式を検証し、不明な施設はナビイの該当ページへ案内。

## 2026-09-09 検索・表示改善

- 医療機関名・住所のキーワード検索を追加。全角英数字・大文字小文字・複数語に対応。
- エリア・距離・ページをURLに保存。詳細から「一覧に戻る」でも条件を維持。
- 条件変更は1ページ目へ戻り、全解除は距離・現在地も解除。
- 駅の選択を常時表示。現在地や駅が未選択のときは距離計算・距離絞り込みをしない。
- 現在地の再利用は同一タブで取得から30分以内。座標はURLに含めず、端末のsessionStorageのみ使用。
- 位置取得の完了前に駅を選んだ場合、遅れて返る現在地で選択を上書きしない。
- 地図ボタンから地図パネルへスクロール。駅を変えたときの地図ラベルも一致。
- 詳細画面を5言語化。言語選択を端末のlocalStorageに保存し、再読み込みでも維持。
- 未確認の英語対応・予約不要・保険情報を断定しない。土日は登録時間と休診日のみから判断。
- スマホのメニュー、選択状態の読み上げ、キーボードのフォーカス、未定義テーマ色を補完。
- フッターの未実装規約をクリック可能に見せず「準備中」と明記。

検証記録: [docs/AUDIT_2026-09-09.md](docs/AUDIT_2026-09-09.md)

## WhatsApp相談の設定（2026-10-05更新）

相談ページはオンライン診療を希望する方へのWhatsAppサポート入口です。タブとトップの入口は「オンライン診療希望の方」に統一しました。有料バッジ、決済、料金サイトへの誘導、電話相談のCTAを削除しました。
旧 `CONSULTATION_PAYMENT_LINK` は使用しません。このリポジトリに含まれない外部サービス自体は変更していません。

2026-10-05に運営者が `070-9036-9655` でWhatsAppを受信できることを確認しました。
確認用ブランチ `codex/medinavi-ux-whatsapp-20261005` のPreview環境に `CONSULTATION_WHATSAPP_ENABLED=true` を設定しました。
本番公開時は、Productionにもこの設定を追加してからビルドしてください。公開前にPreviewの内容を確認します。
未設定時は準備中表示です。受付対応言語・返信時間・個人情報の取り扱いは運営側で確定してください。
この入口自体で診断・処方・予約確定は行いません。

運営者提供の https://ghjapan2025.github.io/nurse-guide-japan/ （公開ソース `ghjapan2025/nurse-guide-japan`, index.htmlのSHA `d015e3267cd18cff672cd414a793944b83626808`、2026-10-05確認）を参考にしました。
追加の相談メニュー・FAQは、運営者の希望に沿って撤去。以前のシンプルな1ページに戻し、オンライン診療の利用方法・予約・受診準備のサポートに説明を限定しました。受診先探しや保険書類の個別相談は案内しません。
WhatsAppボタンで、確認済み番号宛てのオンライン診療希望の下書きが開きます。日本語・スペイン語表示では同言語、それ以外は英語の下書きです。利用者が内容と希望言語を確認して送信し、自動送信はしません。ページの説明は5言語で提供します。
料金、決済、仮の連絡先、サンプル体験談、即時・当日対応や受付時間などの未確認の約束は転記していません。
