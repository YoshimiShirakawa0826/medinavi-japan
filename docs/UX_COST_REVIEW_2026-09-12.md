## 地図の選択肢

| 方法 | 料金の考え方 | 用途・条件 |
| --- | --- | --- |
| Google Maps URLs（今回） | APIキー不要。地図APIのリクエスト課金なし | 施設名＋住所でGoogle Mapsアプリ/サイトを開く。Google掲載の有無・一致によって表示が変わる |
| Google Maps Embed API | Embed SKUは回数無制限・無料 | サイト内に1施設のGoogle地図を埋め込む。Google CloudのAPIキー・請求設定等が必要。キーをサイトとEmbed APIに制限する |
| Maps JavaScript API / Dynamic Maps | 月10,000回まで無料、次の料金帯は1,000回あたり$7 | 複数施設のピンや一覧連動。Places検索など別APIを使う場合は別料金。アラートだけで課金が自動停止するとは限らないため割当も管理 |

当面はMaps URLsで運用し、必要なら選択した1施設だけEmbed APIを読む構成が費用を抑えやすい。緯度・経度だけから施設名が必ず付くわけではありません。

出典：[Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)、[Embed料金](https://developers.google.com/maps/documentation/embed/usage-and-billing)、[Embed設定](https://developers.google.com/maps/documentation/embed/get-api-key)、[Google料金一覧](https://developers.google.com/maps/billing-and-pricing/pricing)。

## 決済と費用

単発相談を最初の対象とし、会員ログイン・課金DB・購入後の自動解錠を作らず、担当者が決済画面で確認する方法を推奨。

| 方法 | 月額固定費 | 基本的なオンライン決済手数料 |
| --- | --- | --- |
| Stripe Payment Links | 標準の単発決済は0円 | カード3.6%。Payment Links自体の追加手数料なし。通貨換算が必要な場合は別途2% |
| Squareリンク決済 | 0円 | 3.6%。カード、Apple Pay、Google Pay等 |

Stripeではカード・Apple Pay・Google Payを基本にし、必要に応じてAlipay・WeChat Pay・PayPayを検討。実際の表示は国・端末・通貨・アカウント審査/設定に依存します。PayPayの標準料率は3.98%、デジタルコンテンツ事業向けは9.48%で、相談サービスの適用区分を確認します。コンビニは3.6%・最低120円で、支払完了まで時間がかかるため即時相談の主手段には向きません。

例：3,000円のカード決済なら3.6%は108円。月100件なら売上30万円に対し手数料10,800円。通貨換算・追加製品・返金等を含めない計算です。標準料金では返金しても元の決済手数料は戻りません。

自動領収書は設定可能。会員・サブスク・自動的なサービス解放を追加する場合は、Webhookで決済を確認し、戻り先URLだけを支払い証明にしない設計が必要です。

出典：[Stripe料金](https://stripe.com/jp/pricing)、[Payment Links](https://docs.stripe.com/payment-links)、[Payment Linksの作成](https://docs.stripe.com/payment-links/create)、[Squareリンク決済](https://squareup.com/jp/ja/payment-links)、[PayPay](https://docs.stripe.com/payments/paypay)、[Alipay](https://docs.stripe.com/payments/alipay)、[WeChat Pay](https://docs.stripe.com/payments/wechat-pay)。

## ホスティングと開始前に決めること

Vercel Hobbyは個人・非商用のみ。事業サイトとしてVercelを継続する場合はProを想定し、開発者1名なら月$20から、利用量による超過等は別途。地図をMaps URLsにし、Stripeの単発リンク決済を使う場合の構成例は「月$20から＋決済手数料＋必要な通信費・ドメイン等」です。実際の契約変更はしていません。

固定費をさらに削る代案は静的サイト向けホスティングへの移行。ただし現状のNext.js動的詳細ページや将来のチャット機能に合わせた変換・移行の工数が必要で、現段階の推奨は現行構成の整理です。

出典：[Vercel Hobbyの利用条件](https://vercel.com/docs/plans/hobby)、[Vercel料金](https://vercel.com/pricing)。

実決済の公開には、税込料金・相談時間・受付日時・対応言語・キャンセル条件、運営者情報、利用する事業用決済アカウントと本番用決済リンクを確定してください。カード番号・秘密APIキーをチャットに送る必要はありません。
