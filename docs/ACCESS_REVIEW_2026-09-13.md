確認日：2026-09-13。前回の公式サイト確認済み10施設を維持し、残り4,420施設を対象に、厚生労働省「医療情報ネット（ナビイ）」の施設詳細ページを調査しました。カード、日本の健康保険、診療科別の予約外診察、外国語対応の予約条件を項目別の出典とともに表示します。

## 確認方法

- [厚生労働省のオープンデータ一覧](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/newpage_43373.html)を再確認。2026-06-01版の診療所施設情報CSV（62列）と診療科・診療時間CSV（36列）には、今回必要なカード・保険医療機関指定・予約外診察の回答欄がないため、施設IDに対応するナビイの公開詳細ページを利用しました。
- 施設IDだけでは確定せず、名称、住所、電話番号を照合。電話の片方が欠ける場合は住所全体の一致を要求しました。名称変更、移転、電話番号相違などは自動転記せず保留しています。
- 説明用ツールチップを除外し、回答の見出しと値を対応させて取得。重複した回答が食い違う場合、空欄、「-」、項目が存在しない場合は未確認とします。
- 診療時間表がある形式と、表がなく予約条件だけを掲載する形式の両方に対応しています。同じ診療科の記載が矛盾する場合は未知の状態を維持します。
- 公開ページの取得は1秒あたり最大2回に制限し、認証要求・アクセス拒否・利用制限には停止する処理を使用しました。検索エンジンの断片、口コミ、第三者の施設紹介から対応可否を推測していません。
- 出典ページの最終更新日と、今回その掲載を確認した日を分けています。施設への電話確認、訪問確認、当日の受入確認ではありません。

## 誤解を防ぐ扱い

| 項目 | 反映の条件・制限 |
| --- | --- |
| クレジットカード | 「クレジットカード決済」の明示回答を使用。「電子決済不可」しかない場合はカードの非対応と断定せず、説明のみ掲載。ブランドや対象診療は未確定。 |
| 日本の健康保険 | 「保険医療機関」の指定記載を使用。対象外の自由診療もあり、全診療の保険適用を保証しない。指定の記載がないだけで「非対応」にはしない。 |
| 海外旅行保険 | 日本の健康保険とは別項目。「対応」の記載だけで、直接請求・キャッシュレス診療に対応すると判定しない。立替払いや事前の支払保証を区別。 |
| 予約なし | 診療科ごとの「予約外診察」の明示回答を使用。「初診時予約未実施」から推測しない。診療科と同時に絞り込む際は、その科目に肯定的な記載がある施設に限定。 |
| 外国語対応 | 外国語診療の予約条件を詳細表示。選択言語に「要予約」の記載がある施設は、予約なしの肯定的検索から除外。 |
| 出典間の相違 | 公式サイトの追加案内を確認し、食い違う条件は明記。平和国際医院の予約条件は要確認として両方の出典を表示。 |

診療科名、対応言語名、原文の備考は取り違えを防ぐため日本語の原文を残し、その旨を5言語で表示しています。一般的な説明と操作ラベルは日本語・英語・中国語・韓国語・スペイン語に対応します。

## 保存と再更新

- `data/nabii-access.json.gz.partNN`：照合済み回答、施設の照合キー、公開出典URL、確認日、出典更新日、元HTMLのSHA-256。施設ページ全体は配信しません。
- `data/nabii-access-manifest.json`：照合件数、調査対象件数、圧縮分割一覧、内容ハッシュ、保留理由の集計。
- `data/nabii-access-holds.json`：転記を保留した施設IDと理由、公開出典。別施設への紐付けや電話番号の自動変更はしません。
- `data/clinic-access-reviews-20260913.mjs`：追加の施設公式サイト確認。今回の4施設はナビイにも含まれる可能性があり、合計は重複を除きます。

次回の取得は、生成済み `public/data/clinics.json` を入力にしないでください。新たな調査用ディレクトリを用意し、元の圧縮データから基準リストを生成します。Python 3とlxmlが調査時だけ必要です。通常のVercelビルドはNode.jsのみで完了します。

```bash
node scripts/prepare-access-base.mjs /tmp/medinavi-review/base-clinics.json
python3 scripts/fetch_nabii_access.py --clinics /tmp/medinavi-review/base-clinics.json --cache /tmp/medinavi-review --workers 4
python3 scripts/extract_nabii_access.py --clinics /tmp/medinavi-review/base-clinics.json --cache /tmp/medinavi-review --output /tmp/medinavi-review/access-facts.json --audit /tmp/medinavi-review/access-audit.json
```

抽出後は旅行保険の候補記載、施設照合の保留、公式サイトとの相違を確認してください。自由文の保険候補を直接請求可として自動登録しません。公式サイトの説明・確認日は、再度内容を確認した時だけ更新します。

```bash
python3 scripts/package_nabii_access.py --facts /tmp/medinavi-review/access-facts.json --audit /tmp/medinavi-review/access-audit.json
npm run prepare:data
python3 -m unittest discover -s tests -p 'test_nabii_access.py'
npm test
npm run lint
npm run build
```

未取得の施設を残したままパッケージ化すると停止します。取得失敗や照合不一致は明示的な保留として保存します。ビルド時は圧縮データの件数・ハッシュ・分割一覧と、各項目の出典・日付・5言語の説明を検証します。

## 運用への影響

静的JSONを通常のビルドで作成し、閲覧時のWeb検索、有料API、AI呼出し、外部データベースを追加していません。配信量はデータ追加により増えるため、既存ホスティングの利用枠は引き続き確認してください。収録4,430施設、電話番号4,316件、元データの日付、電話の出典、直接確認の状態は維持しています。
