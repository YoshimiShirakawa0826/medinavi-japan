## 更新方法

1. `data/clinic-access-reviews.mjs` の施設ID・名称・電話番号と、公式ページの施設所在地を照合する。
2. 項目ごとの条件、5言語の短い説明、公式URL、実際の確認日を追加する。情報が見つからない項目は補完しない。
3. `npm run prepare:data` で元データに重ねる。名称・電話番号の不一致、重複、出典欠落、翻訳欠落、保険請求方式の矛盾があれば停止する。
4. `npm test`、`npm run lint`、`npm run build` とプレビュー画面で確認して公開する。

元の4,430施設・4,316電話番号、施設情報の基準日、電話の出典、直接確認のステータスは維持しています。圧縮元データを変更せず、通常のVercelビルドで再現できます。外部AI・地図・データベースAPIへの追加呼出しはありません。
