## 確認した問題と修正

| 問題 | 修正 |
| --- | --- |
| 距離のローカル状態がURLと不一致。全解除後も半径が残る | URLを検索条件の基準に統一。条件変更でページをリセット |
| 詳細から戻ると検索条件が消える | 一覧URLを安全に保持。外部URLへの戻り先は拒否 |
| 駅選択が一部のエラー時のみ。未選択でも新宿基準の距離が表示 | 駅選択を常設。明示的な基準点なしでは距離表示・絞り込みを無効化 |
| 駅を選んでも地図の見出しが「新宿中心」 | 地図の座標とラベルを同じ選択エリアから作成 |
| スマホで地図が100件の結果の後ろにあり、押しても見つけにくい | 20件表示と地図パネルへのスクロール |
| 名前・住所検索がない | 全言語の名称・住所を対象にNFKC正規化した検索を追加 |
| 詳細の主要項目が言語選択に関係なく英語 | 5言語化。診療時間表も曜日・休診を翻訳 |
| 再読込で言語が英語に戻る | localStorageの設定をhydration-safeに読み込む |
| 英語未登録をLimited、週末の欠損をWeekdays Onlyと表示 | 未確認は要確認。週末は時間表・休診日から三値で判定 |
| 予約不要が詳細にない | 要事前確認を含む項目を追加 |
| スマホでナビゲーション自体が非表示 | 横スクロール可能なモバイルメニューを追加 |
| 無名のアイコンリンク、選択状態・フォーカス表示不足、未定義の色 | aria-label/pressed/expanded、フォーカス、色定義を修正 |
| 規約がリンクに見えるのに押せない | 未実装は「準備中」と表示。規約本文は未作成 |
